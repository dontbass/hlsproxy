Доступ извне (ТВ в другом месте)

Плеер в другом городе подключается к белому IP роутера. Без ключа внешние запросы отклоняются; прокси не пускает внешних клиентов во внутреннюю сеть. Поток идёт через ваш исходящий канал: для UHD нужно ≥ 25–30 Мбит/с отдачи на каждый внешний ТВ. Надёжнее — WireGuard-туннель между роутерами: тогда порт открывать не нужно.
